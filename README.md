# Finance Website Skeleton

A simple finance website skeleton built with **Next.js, Tailwind CSS, and HTML**.

This project provides the basic structure for a stock tracking platform where users can explore different categories of shares.

## Features

- 📈 View all available shares
- ⭐ Save favorite shares
- 🚀 Display top performing shares
- 📊 Browse and explore stock lists

## Tech Stack

- Next.js
- Tailwind CSS
- HTML

## Purpose

This project is a starter template for building a finance or stock tracking web application. It focuses on the core structure and layout of a financial dashboard.
